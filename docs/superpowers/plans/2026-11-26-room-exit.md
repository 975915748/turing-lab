# Room Exit Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans. Implement directly; an independent final reviewer checks the result.

**Goal:** 退出房间释放角色锁名，房主退出安全关闭并保留历史。
**Architecture:** 兼容迁移成员退出原因、裁判退出时间，新增场次校验的 leave/withdraw API；复用短 SQLite 事务和账号/房间通知。
**Tech Stack:** FastAPI, SQLite, vanilla JS, Playwright.
**Spec:** docs/superpowers/specs/2026-11-26-room-exit-design.md

## Global Constraints
- 不改 main、不部署、不动生产数据/密钥。
- 返回大厅是退房；个人中心、刷新、断网不是退房。
- 关闭保留历史，无积分结算；退赛保留回答且不结算退出者。

## Review Focus
- 旧标签页错误场次不得退出新场；并发退出幂等。
- 裁判退出与生成、最终判断并发不应用失效任务。
- 房主在个人中心返回大厅也应退出/关闭原房间。
- 不足两人允许退出但禁止无效开局；剩余已提交者自动揭晓本轮。
- 已完赛离开不改变结算；重开需要确认。
